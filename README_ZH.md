# Call You By Your Name 🎯

> 一款适用于 Forge 1.20.1 的聊天增强模组，让 @ 提醒更加醒目、友好又有趣。💬

![Call You By Your Name 模组截图](docs/callyoubyyourname.png)

## 功能亮点 ✨
- **一键回复的 @ 提醒：** 输入 `@玩家名` 就能发送带有高亮与点击回复按钮的提示，点击即可自动补全对方名字，并可选择播放铃铛提示音。
- **现成的群体召集：** 使用 `@here` 通知同一维度的所有玩家，用 `@near` 召集附近队友；其他模组也能通过注册接口扩展更多群体。
- **分享物品与坐标：** 在消息中加入 `@item`，即可分享主手物品的悬浮提示；使用 `@spot` 则会插入一个可点击的坐标标记。
- **客户端易读性：** 彩色高亮（玩家、群体、物品与坐标）与智能自动补全同步呈现，既好看又好用，同时不会干扰以 `/` 开头的指令输入。
- **防刷屏提醒：** 可调的冷却时间限制刷屏，搭配可开关的提示音，让队友即使没看聊天框也不会错过呼叫。

![点击回复演示](docs/reply.webp)

## 必要条件 📦
- **Minecraft：** Java 版 1.20.1
- **加载器：** Forge `47.4.10`（含）以上，客户端与服务端需保持一致

## 安装步骤 🛠️
1. 安装适配 Minecraft 1.20.1 的 Forge。
2. 将 CallYouByYourName 的 JAR 文件放进 `mods/` 文件夹。
3. 重启游戏或服务器即可加载模组。

## @ 语法速查 📚
| 语法 | 功能 | 备注 |
| --- | --- | --- |
| `@玩家名` | 向单个玩家发送金色提醒，并附带点击回复。 | 无法 @ 自己，重复目标会被自动忽略。 |
| `@here` | 通知同一维度的其他所有玩家。 | 对所有玩家开放使用。 |
| `@near` | 召集半径约 32 格内的队友。 | 仅会在同一维度内搜索。 |
| `@item` | 分享主手物品的悬浮提示信息。 | 主手为空会提示错误并取消发送。 |
| `@spot` | 插入高亮的 “Spot” 链接，鼠标悬停可查看当前位置坐标。 | 用于快速指路或标记地点。 |

## 客户端体验 🌈
- 提示颜色会根据玩家、群体、分享物品以及坐标标记自动变化，聊天内容一目了然。
- 自动补全会列出群体、自定义注册关键词与在线玩家，但在输入 `/` 指令时会自动隐藏。
- 加入服务器时会自动同步（本地或其他模组提供的）群体关键词，无需重启即可更新。

## 配置项 ⚙️
首次启动会生成 `config/CallYouByYourName-common.toml`，可以调整：
- `mentionCooldownMs`：同一玩家连续 @ 的最小间隔（默认 `5000` 毫秒），设置为 `0` 即可关闭限制。
- `enableMentionSound`：是否在被 @ 时播放铃铛声（默认启用）。

修改后重载配置或重启游戏即可生效。

## 拓展接口 🧩
开发者可以实现 `MentionGroupProvider` 并通过 Java `ServiceLoader` 注册，自定义的群体关键词会自动同步给所有在线玩家。

## 常见问题 🧰
- **“为什么我不能用某些群体 @？”** 某些第三方群体可能需要额外权限，被拒绝时会收到红字提示。
- **“自动补全怎么没弹出来？”** 补全功能仅在普通聊天时启用，输入 `/` 指令会自动隐藏。
- **“`@item` 没有成功发送？”** 请确认主手持有物品，否则消息会被取消以提醒你补上物品。
